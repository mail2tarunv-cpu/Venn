Connect your tokens on GitHub

Venn reads one design-token file from a public repository and tells you when a push changes it.

Private repositories need the Venn GitHub App, which is not available yet

Connect your Figma file

Venn changes Figma through a small plugin you run in Figma. It only touches variables you review.

  1. Download the plugin and unzip it
  2. In Figma Desktop, open Plugins, Development, Import plugin from manifest
  3. Open your file and run Venn

Apply in Figma

The plugin compares your Figma file with the latest commit. Tick what you reviewed and it writes only those values, reads each one back, and gives you a receipt.

  1. Open your Figma file and run Venn from Plugins, Development
  2. Review the differences, then press Apply in Figma
  3. Press Record in Venn and this page updates
