Setup

In Figma Desktop: Plugins → Development → Import plugin from manifest. Select manifest.json from the plugin source folder. Open the test file, launch Design Drift Sync, compare, then apply the update. To propose Figma token values back to GitHub, use the plugin to create a reviewable pull request with a fine-grained GitHub token.

The development plugin synchronizes selected tokens in the isolated test file. It does not regenerate component structures or support private repositories and unattended background sync.
